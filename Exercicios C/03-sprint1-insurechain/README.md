# Sprint 1: Validação Lógica, Entrada de Dados e Laços

#### 🚀 Sprint 1 — Validação Lógica, Entrada de Dados, Laços e Menu Principal

**Foco Técnico:** Fundamentos da Linguagem C, Tipos de Dados Primitivos, Pseudocódigo, Lógica Condicional (`if/else`, `switch`), Laços de Repetição (`for`, `while`, `do-while`) e Estrutura de Navegação (Menu CLI).

#### 📦 Itens Detalhados a Entregar

1. **Mapeamento Lógico e Código do Módulo:** Programa em C estruturado descrevendo o passo a passo da solução, menu e regras de validação.

2. **Arquitetura do Menu de Opções Interativo:** Menu CLI em C utilizando `switch` e `do-while`, apresentando as opções:

* **[1] Seleção do Arquivo de Entrada**
* **[2] Processamento do Arquivo de Entrada**
* **[3] Ajuste de Dados do Arquivo**
* **[4] Geração do Arquivo de Saída**
* **[5] Dashboard e Estatísticas**
* **[0] Sair do Sistema**

3. **Entrada Interativa e Validação de Faixa:** Validação de entradas via teclado (`scanf`), utilizando estruturas de repetição (`while` ou `do-while`) para impedir opções inválidas.

4. **Protótipo de Fluxo Completo:** Execução funcional do menu no terminal, com navegação contínua e simulação das ações principais.
