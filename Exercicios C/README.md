## 💻 Exercícios em C

Pequenos exercícios desenvolvidos durante as aulas para praticar
os primeiros conceitos de programação utilizando a linguagem C.

### Conceitos praticados

- Variáveis e tipos de dados
- Entrada de dados com `scanf`
- Saída de dados com `printf`
- Operadores aritméticos
- Expressões matemáticas
- Cálculos utilizando valores fornecidos pelo usuário

### Exercícios

| # | Exercício | Conceito |
|---|-----------|----------|
| 01 | Soma de três números | Entrada, saída e soma |
| 02 | Limite de crédito | Cálculos com valores monetários |
| 03 | Salário do funcionário | Porcentagem e expressões |
| 04 | Velocidade média | Variação de espaço e tempo |
| 05 | Aceleração média | Cálculo de aceleracão |
| 06 | Porcentagem | Operações aritméticas |
| 07 | Cálculo de idade | Entrada e operações |
